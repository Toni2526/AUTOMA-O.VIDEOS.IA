# AUTOMA-O.VIDEOS.IA Este repositório centraliza os agentes de Inteligência Artificial projetados para automatizar a criação, edição e publicação de vídeos. ## Estrutura dos Agentes 1. Agente Coordenador: Gerencia as tarefas, delega subtarefas e solicita autorização para ações críticas. 2. Desenvolvedor de Sites e Aplicativos: Escreve códigos e integra APIs. 3. Especialista em Geração de Imagens: Usa APIs como DALL-E 3, Leonardo.ai ou Hugging Face. 4. Criação de Vídeos: Produz takes curtos com tecnologias como Kling AI. 5. Textos e Roteiros: Gera materiais escritos com o Gemini ou Groq. 6. Automação: Gerencia fluxos via GitHub Actions. 7. Testes e Qualidade: Avalia os padrões e a segurança. 8. Integração por MCP: Conecta IA a sistemas locais. 9. Publicação Automática: Publica conteúdos com base em tendências. 10. Armazenamento e Organização: Estrutura os arquivos e pastas do projeto. ## Estrutura de Pastas - Agentes/ - Projetos/ - Multimidia/ - Roteiros/ - Testes/ - Documentacao/
